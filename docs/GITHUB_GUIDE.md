# GitHub Setup & 6-Day Commit Plan

- **Recommended Repo Name:** `Email-Automation-Reminder-System`
- **Description:** Python email automation and recurring reminder engine using Jinja2 templates, RRULE expansion, SQLite logging, and dry-run SMTP simulation.
- **Tags:** `python`, `email-automation`, `jinja2`, `smtp`, `fastapi`, `rrule`, `scheduling`

## 6-Day Commit Plan
1. **Day 1:** Repo setup, `.env.example`, `.gitignore`, and sample contacts/reminders CSVs.
2. **Day 2:** Jinja2 HTML template renderer (`src/renderer.py`) and recurrence expander (`src/scheduler.py`).
3. **Day 3:** Safe SMTP mailer with dry-run mode (`src/mailer.py`).
4. **Day 4:** SQLite logging, unsubscribe filtering, and CSV report export (`main.py`).
5. **Day 5:** FastAPI log endpoint (`api/app.py`) and tracking webhooks (`src/webhooks.py`).
6. **Day 6:** Unit tests, `README.md`, and interview prep docs.
